# Go Auto Brackets

Расширение VS Code на TypeScript для автоматических скобок вокруг возвращаемых типов Go-функций. Работает только в документах с языковым режимом **Go** (в том числе в ещё не сохранённых).

Введите **запятую** после единственного возвращаемого типа:

```go
func foo() int {}
// После ввода запятой (| обозначает курсор):
func foo() (int, |) {}
```

После запятой добавляется один пробел, курсор оказывается перед `)`. Можно сразу вводить следующий тип.

Удалите запятую из `(int, )` — получите `int`. Можно также выделить и удалить `, error` из `(int, error)` — останется `int` без скобок.

Если удалить только запятую из `(int, error)`, скобки сохранятся: два типа ещё не превращаются в один. Скобки сохраняются и у именованного результата `(value int)`, поскольку Go требует их.

Поддерживаются обычные функции, методы, обобщённые функции, функциональные типы и литералы функций. Учитываются вложенные типы, комментарии и строки. Для сигнатур методов внутри `interface`, не содержащих `func`, автоматизация не предусмотрена.

Запятые внутри списка параметров не запускают автоматизацию, в том числе после результата callback-параметра: `func foo(callback func() int, next string)`.

## Установка

Готовый файл `go-autobrackets-0.1.2.vsix` можно установить через команду VS Code **Extensions: Install from VSIX…** или терминал:

```sh
code --install-extension go-autobrackets-0.1.2.vsix
```

Для сборки из исходников нужен Node.js 20 или новее:

```sh
npm ci
npm test
npm run package
```

Для разработки откройте проект в VS Code и нажмите **F5**. В открывшемся Extension Development Host создайте `.go`-файл и проверьте пример выше. Дополнительно проверьте Backspace после запятой, удаление выделенного `, error`, Undo/Redo и отсутствие изменений в файле с языком TypeScript.

## Настройка

```json
{
  "goAutobrackets.enabled": true
}
```

Автоматизация рассчитана на один курсор и отдельный ввод запятой либо удаление фрагмента с запятой. Массовая вставка, несколько курсоров и Undo/Redo не запускают преобразования. Если документ изменился до применения автоматической правки, устаревшая правка пропускается. Удаление скобок при наличии `//` внутри списка результатов пропускается, чтобы комментарий не поглотил код.

Расширение не требует Go, gopls или других расширений. Использует небольшой лексический разбор сигнатур, а не полный компилятор Go. Изменения применяются через [VS Code TextEditor API](https://code.visualstudio.com/api/references/vscode-api#TextEditor) вместе с исходным вводом в одной группе Undo.
